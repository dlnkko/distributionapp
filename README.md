# distributionapp

Exposure and distribution app: businesses pay to get listed, users type a pain point and get matched to a software, service, product, freelancer, or business.

## Local

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and fill in Supabase, OpenAI, and Firecrawl keys.

## Stack

- Next.js
- Supabase (auth + database)
- OpenAI GPT-5.6
- Firecrawl
